## Triggers

| Trigger | Use it to |
| --- | --- |
| **When lead created** | Start follow-up for new leads. |
| **When new message arrives** | Respond to customer messages quickly. |
| **When call missed** | Recover calls with instant text-back. |
| **When no reply after 24 hours** | Nudge leads who go quiet. |
| **When appointment booked** | Send reminders or confirmations. |
| **When quote approved** | Act when a customer approves a quote. |
| **When payment received** | Run after a successful payment. |
| **When review posted** | Handle new reviews automatically. |
| **When campaign reply received** | Route campaign replies. |

## Actions

| Action | What it does |
| --- | --- |
| **Send SMS** | Texts the contact your message. |
| **Send WhatsApp** | Sends your message on WhatsApp. |
| **Send Review Request** | Asks the contact for a review. |
| **Send Payment Reminder** | Reminds the contact about an unpaid payment. |
| **Assign to Team Member** | Gives the contact or conversation to a teammate. |
| **Add Tag** | Tags the contact. |
| **Create Follow-up Task** | Adds a follow-up task for your team. |
| **Generate AI Reply** | Has the AI write a reply. |
| **Send AI Follow-up** | Has the AI write and send a follow-up. |

## AI behaviors

With **Use AI Agent** on, choose how the AI handles the message:

| Behavior | What it does |
| --- | --- |
| **Write short reply** | A brief, friendly message. |
| **Write detailed reply** | A fuller answer. |
| **Ask for review** | Asks the customer for a review. |
| **Follow up with lead** | Re-engages a lead. |
| **Answer using knowledge base** | Answers from your [Knowledge Hub](/ai/knowledge-hub). |
| **Escalate if unsure** | Passes the conversation to your team if it isn't confident. |

## Conditions

| Condition | Example |
| --- | --- |
| **Contact Stage** | Only for leads |
| **Contact Tag** | Only for "Maintenance plan" customers |
| **Payment amount above** | Only for payments over $500 |
| **Business hours only** | Only during your working hours |
