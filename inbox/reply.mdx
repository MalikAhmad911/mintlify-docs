Open a conversation and type in the composer at the bottom.

## Composer tools

| Tool | What it does |
| --- | --- |
| **Templates** | Insert a [canned response](/inbox/canned-responses). |
| **Add emoji** | Add an emoji to your message. |
| **Add note** | Leave an internal note for your team. Customers never see notes. |
| **Request payment** | Send a payment link by text. |
| **Send review** | Send a review request. |
| **Call** | Call the customer from your browser. |

<Note>
  Attachments aren't available yet in the composer.
</Note>

## AI-suggested replies

In **Draft** mode the AI suggests a reply. Edit it if you need to, then send. See [Conversation modes](/inbox/overview#conversation-modes).

## Message actions

Open **More actions** on a message to **Forward** it or **Delete** it.

## Calls in a conversation

When a call is in progress you'll see **Ongoing call** with **Mute**, **Hold**, **Keypad** and **End call**.

## Quick actions

The contact panel's **Quick actions** let you **Request payment** or **Send review request** in one click. See [Contact panel](/inbox/contact-panel).
