Open **Payments** to "send payment links, track collections, and manage invoices." Payments are included on **Professional** and up.

## At the top

| Number | What it shows |
| --- | --- |
| **Collected this month** | Payments received this month. |
| **Total all time** | Everything collected so far. |
| **Paid**, **Pending**, **Sent** | How many payment requests are in each state. |

## Payment request statuses

| Status | Meaning |
| --- | --- |
| **Pending** | Created and waiting for the customer to pay. |
| **Sent** | The link was sent and is waiting to be paid. |
| **Paid** | The customer paid. |
| **Expired** | The link is no longer valid. |
| **Refunded** | The payment was refunded. |

Use **Search payments...** and **All Statuses** to find a payment.
